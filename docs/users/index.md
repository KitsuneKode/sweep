Start with [Getting started](getting-started.md), then learn the
[terminal UI](terminal-ui.md) or [command workflow](commands.md).
Use [Automation and streaming JSON](automation.md) for scripted consumers.

Before your first deletion, read [Safety and trash](safety.md). If you maintain
several projects, use [Configuration](configuration.md) to exclude valuable
outputs. [Platforms and large trees](platforms.md) explains runtime requirements
and what happens when a scan reaches a resource limit.

[Privacy and sharing](privacy.md) covers saved plans and history.
[Troubleshooting](troubleshooting.md) starts from the message you see.
