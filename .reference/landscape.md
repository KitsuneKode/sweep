# Cleanup Tool Landscape

Useful comparison points for `sweep`:

- `npkill` — strong interactive inspiration, especially around selection and
  candidate review
- `kondo` — broad project-cleanup framing
- `Dustoff` — examples of richer JS/TS TUI cleanup UX

This file is intentionally lightweight. It is not the source of truth for
product direction; `.docs/product-direction.md` and `.docs/decision-log.md`
own accepted project decisions.
